# Workout Plan 💪

Your personal 7-day lean body blueprint — meals, workouts, habit tracking and progress logging.

## Deploy to GitHub Pages (5 minutes)

### Step 1 — Create a GitHub repository
1. Go to [github.com](https://github.com) and sign in (or create a free account)
2. Click **+** → **New repository**
3. Name it `workout-plan`
4. Set to **Public**
5. Click **Create repository**

### Step 2 — Upload these files
1. Click **Add file → Upload files**
2. Drag and drop **all files and folders** from this ZIP:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icons/` (the whole folder)
   - `README.md`
3. Click **Commit changes**

### Step 3 — Enable GitHub Pages
1. Go to your repository **Settings**
2. Click **Pages** in the left sidebar
3. Under **Source** → select **Deploy from a branch**
4. Set branch to `main`, folder to `/ (root)`
5. Click **Save**

### Step 4 — Open your app
After ~60 seconds your app will be live at:
```
https://YOUR-USERNAME.github.io/workout-plan
```

Open this URL in **Chrome on your phone**.

### Step 5 — Install to home screen
- Chrome will show an **"Add to Home Screen"** banner automatically after a few seconds
- Or tap **⋮ menu → Add to Home Screen → Install**
- The app will appear on your home screen with the WP icon
- Opens fullscreen with no browser bars ✅
- Works offline ✅
- Your data saves permanently ✅

## Features
- 📅 7-day plan with meals, workouts and timings
- ✅ Daily checklist for 13 healthy habits  
- 💧 Water intake tracker (8 glasses)
- ⚖️ Weight log with trend chart
- 🏋️ Workout logger with sets/reps
- ✏️ Edit task times and reorder your schedule
- 📊 Weekly compliance overview
- 🌙 Full dark mode

## Data storage
All your data is stored in your browser's **local storage** on your device. It is never sent to any server. Clearing your browser data will erase your progress, so avoid doing that once you start tracking.
